# Agu Nigeria

### E-Commerce Website

**Live Website:** https://agu.ng/

**Year Developed / Launched:** 2020

## Overview

Agu Nigeria is an e-commerce website built to provide an online shopping experience for customers, with product browsing, shopping and checkout functionality powered by WooCommerce.

I worked on the development of the website, implementing the frontend experience, WooCommerce functionality, backend technologies and third-party service integrations.
